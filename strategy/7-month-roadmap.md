# 7-Month Roadmap — Brazilian Backend Dev → AI Agent Engineer (USD Remote)

Baseado em transição do R$10-15k/mês local pra R$25k+/mês via contrato USD remote.

**Premissa**: você já tem 2-4 anos de backend sólido. Esse roadmap não é pra quem tá começando.

---

## Mês 1 — Posicionamento

**Objetivo**: parar de parecer "full stack genérico" e começar a parecer "AI Agent Engineer com produção".

**Tarefas**:

- [ ] Reescreve LinkedIn (headline + About + skills reordering) — usa as peças desse kit
- [ ] Reescreve GitHub README do perfil — usa o template em `github/profile-readme.md`
- [ ] Sobe banner novo no LinkedIn — `banner/banner.png`
- [ ] Configura "Open to Work" em `recruiters only` (não público)
- [ ] Lista os 3 projetos que vão virar teu portfolio público
- [ ] Bloqueia 4-6h/semana fixas pra trabalho de portfolio (não negociável)

**Sinal de "tá no caminho"**: terminou o mês com perfil novo no ar e roadmap dos 3 projetos.

---

## Mês 2 — Construir o portfolio público (parte 1)

**Objetivo**: 1 projeto público sério com README forte.

**Escolha do projeto**: ele precisa ter:

- Arquitetura defensável (não é só "chamei API e funcionou")
- Decisões técnicas explicáveis em entrevista
- Produção de verdade (rodando em algum lugar, idealmente AWS/GCP/Vercel)
- 1 página de README com diagrama, decisões, e como rodar

**Anti-projetos**:

- ❌ ChatGPT clone — todo mundo tem
- ❌ Tutorial de RAG genérico — todo mundo tem
- ❌ App fullstack to-do com IA — não impressiona

**Bons exemplos**:

- ✅ Agente que automatiza algo específico do teu domínio (financeiro, legal, devops)
- ✅ Trading bot real com backtesting + risk management
- ✅ Tooling pra Claude Code / MCP server pra um workflow específico
- ✅ RAG sobre dataset peculiar (regulação brasileira, leis municipais, manuais técnicos)

**Tarefas**:

- [ ] Define escopo (1 frase do problema + 3 pontos de arquitetura)
- [ ] Escreve README primeiro, código depois (força claridade)
- [ ] Sprint focado, fim de semana
- [ ] Commit público na primeira versão minimamente funcional

---

## Mês 3 — Portfolio parte 2 + estudo de gaps

**Objetivo**: 2º projeto + fechar gaps técnicos do nicho.

**Gaps críticos pra AI Agent Engineering em 2026**:

1. **Evals e observabilidade pra LLM** — LangSmith, Braintrust, Inspect AI. Quase ninguém sabe fazer direito. Paga muito.
2. **RAG em produção** — não tutorial. Chunking strategies, hybrid search, rerankers, query rewriting.
3. **Agent architecture patterns** — multi-agent, routing, tool use, error recovery.
4. **MCP** — escrever servers próprios, não só consumir.

**Tarefas**:

- [ ] Escolhe 1 dos 4 gaps acima e estuda em profundidade (~20h)
- [ ] Construa um mini-projeto demonstrando esse gap fechado (vira o 2º projeto público)
- [ ] Inglês técnico de entrevista — pratica system design em inglês 2-3x na semana, em voz alta

---

## Mês 4 — Pipeline (aplicação)

**Objetivo**: estar em pipeline ativo de 5-10 oportunidades.

**Tarefas**:

- [ ] Cria perfil em **Turing** (faz triagem técnica logo no início)
- [ ] Aplica em **Toptal** (entrevista mais séria mas paga melhor)
- [ ] Cria perfil em **Arc.dev**, **Lemon.io**, **Braintrust**
- [ ] Cold outreach pra 20-30 startups em paralelo (Wellfound, job board do Hugging Face, AI Grant batch companies)
- [ ] Atualiza CV em PDF curto (1 página, focado em projetos públicos)

**Volume importa**: assume conversão de 5-10% applies → entrevista. Pra ter 3 entrevistas, manda 30+ aplications.

---

## Mês 5 — Entrevistas + 3º projeto

**Objetivo**: passar por 3-5 entrevistas técnicas, aprender com cada uma.

**Estratégia**:

- Trata as 3 primeiras como "entrevista de treino" — vai bem se passar, mas o objetivo principal é aprender o padrão das perguntas
- Toma notas detalhadas após cada uma — quais perguntas, como respondi, o que travou
- Itera o GitHub README e About do LinkedIn baseado em feedback indireto (palavras que recrutador usou, perguntas que ele fez)

**Tarefas em paralelo**:

- [ ] 3º projeto público (consolidação do que aprendeu nos 2 primeiros)
- [ ] Pratica entrevista técnica com amigo dev em inglês, semanal
- [ ] Aplica em mais 10-15 oportunidades

---

## Mês 6 — Fechar primeiro contrato

**Objetivo**: assinar contrato USD.

**Faixa esperada**:

- Mid-level offshore: US$40-60/hora
- Senior offshore: US$60-90/hora
- Specialist (AI agent, niche): US$80-150/hora

A 25h/semana, US$50/h = US$1,250/semana = US$5k/mês = ~R$25k/mês.

**Tarefas**:

- [ ] Negocia rate (não aceita primeiro número, sempre)
- [ ] Estrutura jurídica/fiscal pra receber USD (PJ, MEI não vai dar conta)
- [ ] Conta em banco que recebe USD (Wise, Nomad, BTG)
- [ ] Lê o contrato com atenção (NDA, IP assignment, non-compete)

---

## Mês 7 — Transição

**Objetivo**: largar uma das pontas brasileiras pra ramp-up no contrato USD.

**Lógica**:

- Se o contrato USD é 25h/semana e tu trampa 60h/semana hoje, larga o trampo BR de menor leverage
- Não larga tudo de uma vez — mantém pelo menos 1 receita BR como segurança nos 2-3 primeiros meses do contrato USD
- Mantém disciplina financeira — não infla custo de vida nos primeiros meses

---

## Coisas pra NÃO fazer durante o roadmap

- ❌ Começar SaaS — divide foco, retorno demora
- ❌ Pegar 3º trampo BR — hora marginal em real é o pior trade pro perfil
- ❌ Otimizar investimento ou trading pessoal — ganho marginal é nada perto de +R$10k/mês de renda
- ❌ Mudar de stack completamente (ex.: aprender Rust do zero) — usa o que já sabe
- ❌ Esperar "estar pronto" pra aplicar — competência se prova em entrevista, não em LinkedIn
