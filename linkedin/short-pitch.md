# Short Pitch — for cold outreach, DM, email

Versão curta (~250 chars) pra usar em:

- Cold email pra fundador/CTO
- DM no LinkedIn como abertura
- Bio do Twitter/X
- Resposta a recrutador que pediu "tell me about yourself"

---

## Versão curta (em inglês)

```
AI Agent Engineer building production LLM systems on AWS. Backend foundation in Python/Django, now shipping autonomous workflows — including a live crypto trading agent and tooling for agentic dev workflows. Open to USD remote contracts.
```

---

## Versão curtíssima (uma frase)

```
AI Agent Engineer shipping production LLM systems — Python backend foundation, now building autonomous workflows on AWS.
```

---

## Cold email template

```
Subject: AI Agent Engineer — production experience, USD remote

Hi [name],

I noticed [specific thing about their company / recent post / job posting].

Quick context on me: I'm an AI Agent Engineer with strong Python/Django
backend foundation. Currently shipping a live crypto trading agent on AWS
(Terraform, multi-strategy, Binance Futures) plus tooling around Claude Code
and MCP servers for agentic dev workflows.

I'm open to USD remote contracts, part-time or full. Happy to share specifics
on the trading agent architecture or my agent infrastructure work if useful.

GitHub: github.com/[YOUR_GITHUB]
LinkedIn: linkedin.com/in/[YOUR_LINKEDIN_SLUG]

[Your name]
```

**Personaliza sempre o "specific thing"**. Email genérico vai pra spam mental do recrutador.

## Anti-padrões

- ❌ "Looking for opportunities" sem contexto — todo mundo escreve isso
- ❌ Lista longa de tech sem peso — recrutador conta tags, não conteúdo
- ❌ "I'm passionate about AI" — palavras vazias
- ❌ Não pedir nada concreto — sem CTA, vira monólogo
