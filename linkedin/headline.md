# LinkedIn Headline

Cola direto no campo "Headline" do LinkedIn (a linha sob teu nome).

**Limite**: 220 caracteres.

---

## Versão principal (recomendada)

```
AI Agent Engineer · Building production LLM systems & autonomous workflows · Python Backend · Open to USD remote contracts
```

---

## Variações

**Mais técnica**:
```
AI Agent Engineer · LLM Systems · MCP · Python Backend · Production AWS · Open to USD remote
```

**Mais focada em outcomes**:
```
I ship production AI agents · Backend foundation in Python/Django · Open to USD remote contracts
```

**Versão pt-BR (se preferir manter LinkedIn em português)**:
```
Engenheiro de Agentes de IA · Sistemas LLM em produção · Python · Backend · Aberto a contratos remotos USD
```

---

## Por que essas funcionam

- **"AI Agent Engineer"** primeiro: recrutador busca por job title. Sem isso, tu não aparece em search.
- **"Production"** ou **"Building production"**: separa de quem só fez tutorial.
- **"Open to USD remote contracts"** no final: filtro mais importante pra recrutador estrangeiro. Sinaliza disponibilidade clara.
- Sem **"passionate about"**, **"results-driven"** ou outras palavras vazias. Headline é real estate caro — cada palavra paga aluguel.

---

## Anti-headlines (não use)

- ❌ "Software Engineer | Passionate about AI" — vazio, não diz o que tu faz
- ❌ "Full Stack Developer with experience in many technologies" — diluído
- ❌ "Aspiring AI Engineer" — sinal de inexperiência mesmo se tu não for inexperiente
- ❌ "Helping companies achieve their goals through technology" — buzzword soup
